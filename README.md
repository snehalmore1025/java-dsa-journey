## 📚 Learning Approach

Each study day follows a consistent workflow:

1. **Learn:** Understand concepts through detailed explanations and examples.
2. **Take notes:** Document theory, important observations, and Java syntax.
3. **Practise:** Implement small Java programs and test different inputs.
4. **Dry run:** Trace the code step by step to understand its execution.
5. **Solve problems:** Apply concepts to LeetCode challenges.
6. **Analyse:** Review time complexity and auxiliary space.
7. **Document:** Maintain individual problem READMEs and learning summaries.
8. **Commit:** Submit completed work using Git and GitHub.
